## What is NovaMind AI?

NovaMind AI is a cloud-native SaaS platform that enables businesses to build, deploy, and manage AI chatbots powered by foundation models via AWS Bedrock. It abstracts the complexity of AWS infrastructure so developers can focus on building great conversational experiences.

## Tech Stack

- **AI/ML:** AWS Bedrock (Claude, Titan, Llama)
- **Backend:** AWS Lambda (Python), AWS API Gateway
- **Database:** Amazon DynamoDB (conversation memory)
- **Storage:** Amazon S3
- **Search:** Amazon Kendra
- **Monitoring:** Amazon CloudWatch
- **IaC:** Terraform

## Features

- 🧠 Multi-model support via AWS Bedrock
- ⚡ Serverless, auto-scaling Lambda backend
- 💬 Persistent conversation memory (DynamoDB)
- 🔌 1-line website embed
- 📊 Real-time analytics dashboard
- 🔒 Enterprise security (IAM, VPC, encryption)
